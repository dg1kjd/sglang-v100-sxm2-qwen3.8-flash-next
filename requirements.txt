# SGLang V100 (sm70) -- validated dependency floor
#
# These are the versions this port is built and tested against. They are NOT
# upstream SGLang's pins: upstream targets the CUDA 13 stack, and CUDA 13
# dropped Volta (sm70) entirely. This file is the cu12 floor that keeps V100
# working.
#
# Install with --no-deps (see docs/v100/INSTALL.md); letting pip resolve freely
# will pull the cu13 wheels and break the build.
#
#     pip install --no-deps -r requirements.txt
#
# Three entries are deliberately *not* here because they are built from source
# for sm70 -- see INSTALL.md:
#   flashinfer-python   (patched, patches/flashinfer-sm70.patch)
#   sglang-kernel       (built with -DSGL_KERNEL_V100_ONLY=ON from python/sglang/kernels/aot)
#   marlin_v100         (GPTQ/AWQ + NVFP4 MoE kernels, built by scripts/setup_v100_marlin.sh)
